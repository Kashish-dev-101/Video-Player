# Video Player Workspace

This folder now has two separate player experiments so each path stays easy to understand and maintain.

## Folders

### `native-videojs-player`

This contains the original Video.js-based player demo that tests:

- Progressive MP4 playback
- HLS and DASH playback
- Adaptive bitrate quality selection
- ImageKit-friendly stream URL handling

### `imagekit-player-sdk`

This contains the newer ImageKit player SDK playground that we are building step by step using simple HTML, CSS, and JavaScript.

## Why this structure

- Keep the old Video.js demo intact
- Give the new ImageKit player work its own space
- Make comparison between both approaches easier
